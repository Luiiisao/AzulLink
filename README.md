# AzulLink

Protótipo de centralização e contextualização de ocorrências operacionais desenvolvido para a Seletiva Azul 2026.

## Sobre o projeto
O AzulLink visa resolver o problema de comunicação fragmentada entre as áreas operacionais durante uma ocorrência de voo.

## Problema
Informações detalhadas e técnicas são distribuídas sem contexto único, gerando dessincronia entre CCO, manutenção, handling, comercial e atendimento. O cliente fica sem informação adequada.

## Solução
Uma ocorrência, uma fonte, diferentes contextos. O sistema centraliza a causa raiz e redistribui automaticamente recortes relevantes para cada área envolvida.

## Funcionalidades
- Dashboard para acompanhamento de voos.
- Cadastro centralizado de ocorrências.
- Geração automática de comunicações contextualizadas.
- Visão específica para áreas operacionais e passageiros.

## Tecnologias utilizadas
- React e Vite
- CSS Tradicional
- React Router DOM
- Lucide React
- LocalStorage

## Estrutura do projeto
O código foi construído sem dependência de APIs externas, utilizando armazenamento local para simular a persistência de dados e estado.

## Como executar
1. npm install
2. npm run dev

## Limitações
Protótipo acadêmico. Os dados são salvos apenas no navegador do usuário via LocalStorage.
